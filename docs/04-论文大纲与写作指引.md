## 二、各章内容

### 第 1 章 绪论

- 1.1 说明轻食消费线上化、预制菜效期约束与餐饮管理数字化需求。
- 1.2 分别梳理餐饮外卖系统、即时配送调度、预制菜供应链与效期管理研究现状。
- 1.3 列出系统研究内容，对应系统总体设计中的核心设计模块。
- 1.4 说明各章内容与全文组织结构。

### 第 2 章 相关技术介绍

- 说明 Spring Boot 自动配置与 Starter 机制。
- 说明 MyBatis-Plus 的 Mapper、Wrapper、分页与乐观锁支持。
- 说明 MySQL、Redis 在数据存储、缓存与库存控制中的用途。
- 说明 Vue3、Vite、Element Plus、Vant 与 Pinia 的工程用途。
- 说明 JWT 结构、签名校验、令牌过期与 Redis 黑名单机制。

### 第 3 章 系统分析

内容以 `01-需求分析.md` 为准。

- 角色用例图与角色权限矩阵。
- 用户端、管理端、配送员端功能需求表。
- 订单主流程、配送流程与订单状态机。
- 核心表数据字典。
- 性能、安全、可靠性、可用性、可维护性与可移植性需求。

### 第 4 章 系统设计

- 4.1 展示客户端层、应用层、服务层与数据层架构。
- 4.2 展示后端业务模块与三端功能模块。
- 4.3 展示 E-R 图、核心表结构、订单快照、逻辑删除与索引设计。
- 4.4 展示订单状态迁移表、状态图与状态副作用。
- 4.5 展示候选集筛选、距离、负载、评分三因子归一化与加权排序流程。
- 4.6 展示起步价、里程费、夜间附加费与满额免运费规则。
- 4.7 展示统一响应格式、主要 RESTful 接口与错误码。

### 第 5 章 系统实现

- 5.1 展示工程目录、依赖与运行环境。
- 5.2 展示统一响应、全局异常、JWT 与 RBAC 实现。
- 5.3 展示商品、购物车、订单、支付、预约配送与个人中心实现。
- 5.4 展示商品、订单、配送、批次、库存与数据看板实现。
- 5.5 展示任务大厅、抢单、取货、送达与业绩统计实现。
- 5.6 展示关键功能界面及对应业务流程。

### 第 6 章 系统测试

- 功能测试：登录、购物车、下单、支付、状态流转、运费计算、派单、抢单与权限控制。
- 接口测试：认证、参数校验、幂等性、状态冲突与越权访问。
- 性能测试：商品列表、提交订单与看板统计。
- 安全测试：密码存储、SQL 注入、XSS、越权与文件上传。
- 测试结果记录实际测试环境、输入、预期结果、实际结果与是否通过。

### 第 7 章 总结与展望

- 总结系统实现范围、核心设计与测试结果。
- 列出支付沙箱、动态路况与算法权重等实际限制。
- 说明后续可接入的真实支付、路径规划与动态调度能力。
