# 第 6 章 系统测试

本章记录系统测试的目标与环境，给出功能、接口、性能与安全四类测试的输入与结果，并给出测试结论。

## 6.1 测试目的与方法

测试目标是验证系统实现满足第 3 章的需求：功能上覆盖注册登录、购物车下单、支付、状态流转、运费计算、抢单与权限控制；接口上验证参数校验、数据边界、状态冲突与越权访问；性能上确认接口响应时间满足非功能需求；安全上检验注入、跨站脚本与越权等风险的防护效果。

测试环境为 Windows 11，后端 JDK 17、MySQL 8.0 与 Redis 7.x，自动化测试采用 JUnit 5 与 AssertJ，前端以 pnpm 执行 lint、类型检查与单元测试，性能测试使用 Apache JMeter。测试与端到端验证由 `scripts/verify-release.ps1` 脚本组织，支持在全新数据库上一键执行测试、启动三端并冒烟验证。

## 6.5 安全测试

安全测试覆盖六类风险，除密码以 BCrypt 哈希存储外，其余均在表 6-2 中逐项记录：SQL 注入与跨站脚本载荷分别按普通文本处理与文本渲染（J-04、J-05）[28-30]，文件上传限制类型与大小并要求管理员令牌（J-06），订单金额服务端计算（J-07），支付回调幂等（J-08），越权访问返回 401/403（J-03）。此外，全新环境验证中 Flyway 11 个迁移成功建库，后端与三端在全新数据库上启动并以种子账号登录成功，退出码为 0，系统具备可重复初始化能力。

## 6.6 测试结论

四类测试结果表明：11 组功能用例覆盖核心业务链路并全部通过；接口测试验证了参数校验、状态冲突与越权访问的错误处理契约；三个核心接口平均响应时间均低于 500ms；安全测试表明系统对注入、脚本、非法上传、金额篡改、越权与重复回调均具备预期防护。测试结果与第 3 章非功能需求逐项对应，未发现阻塞性缺陷，系统达到验收标准。

## 6.7 本章小结

本章说明了测试目的与环境，记录了功能、接口与安全测试的输入与结果，给出 JMeter 性能数据，并在全新环境完成初始化验证，确认系统功能、性能与安全指标满足设计要求。
