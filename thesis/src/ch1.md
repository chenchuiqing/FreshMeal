# 第 1 章 绪论

## 1.1 研究背景与意义

随着居民健康意识增强和数字生活方式普及，轻食消费呈现明显的线上化趋势。轻食沙拉、低脂餐、即食鸡胸肉等产品以低油低盐、营养可控为卖点，正从线下门店走向线上商城。消费者下单时普遍关注热量、蛋白质、过敏原等营养参数，这对商品建模与检索能力提出了更细粒度的要求。

预制菜行业的快速发展则改变了餐饮供应链形态。预制菜由中央厨房集中生产、经冷链交付，保质期短、效期管理严格，超过食用期限只能报损。线上订餐系统必须将批次效期纳入库存管理，遵循先到期先出（First Expired First Out，FEFO）原则，在履约时扣减具体批次库存并对临期批次预警，这是本课题区别于通用电商系统的核心业务特征。

在履约层面，餐饮外卖的竞争力集中体现为配送时效。订单从支付成功到送达，需经商家接单、备餐出餐、配送员取货等环节，涉及消费者、商家管理员、配送员三类角色协同。高峰时段如何将订单合理分配给合适的配送员，如何设计可配置的配送费规则，如何保证订单状态在多方操作下始终一致，都是系统设计必须回答的问题。本系统面向轻食预制菜场景提供一体化的订购与配送管理方案，具有明确的现实意义。

本课题在工程实践上覆盖前后端分离架构下的完整业务闭环，包括批次库存、订单交易、预约配送、派单调度与经营看板，可为同类餐饮信息化系统提供设计参考；在知识综合上，将状态机建模、乐观锁并发控制、多因子加权评分与规则引擎应用于真实业务，是对本科阶段所学知识的系统性检验。

## 1.2 国内外研究现状

**餐饮外卖系统研究现状。** 国外学者系统研究了在线订餐平台的体系结构，文献 [1] 设计实现了在线食品订购系统并梳理其功能架构，指出订单状态可视化追踪是提升用户信任的关键。国内研究更贴近平台实践，文献 [2] 设计并实现了基于 Java 的网上订餐系统，文献 [3] 面向高校食堂设计了智慧化点餐与营养分析系统。现有研究已完成从单体订餐网站到分离式平台的演进，但较少涉及预制菜效期约束下的库存扣减策略。

**即时配送调度研究现状。** 传统车辆路径问题多采用遗传算法、蚁群算法等启发式方法求解，文献 [4] 将人工生态系统优化应用于带容量约束的车辆路径问题。即时配送场景兴起后，研究重心转向订单与运力的实时匹配：文献 [5] 提出强化学习与解耦策略相结合的外卖订单匹配指派算法，文献 [6] 构建了以外卖骑手为中心的深度强化学习订单推荐框架，文献 [7] 引入旅行时间预测因子实现即时配送订单的准时指派。上述成果为本系统派单算法的因子选择与权重设计提供了直接依据。

**预制菜供应链与效期管理研究现状。** 文献 [8] 综述了肉类预制菜全产业链的质量安全控制技术，强调全程追溯的必要性；文献 [9] 面向易腐品库存研究了学习型订货策略以降低损耗；文献 [10] 以质量水平为变量优化了乳制品冷链物流的库存策略；文献 [11] 模拟了冷链温度波动对产品品质劣变的影响，为效期约束下的库存管理提供了实验依据。这些研究为本系统的批次表、库存流水设计以及 FEFO 出库与回补实现提供了理论支撑。

**相关技术研究现状。** Spring Boot 通过自动配置与 Starter 机制简化了企业级应用搭建，已成为 Java Web 开发的事实标准，文献 [12] 系统阐述了其核心思想与自动配置原理；文献 [13] 深入解析了 Vue.js 的设计与实现；JWT 已成为分布式会话的通用方案，文献 [14] 规范化定义了其结构、签名与过期校验规则。这些技术构成了本系统的选型基础。

## 1.3 主要研究内容

本课题设计并实现面向轻食预制菜场景的线上订购配送管理系统，为消费者、商家管理员、配送员三类角色提供服务，系统总体功能结构如图 1-1 所示。主要研究内容包括：

（1）**系统总体架构与前后端分离方案**。设计四层架构，制定统一的 RESTful 接口规范、响应格式与错误码体系。

（2）**基于状态机的订单生命周期建模**。以集中式迁移表管控订单全部状态流转，并为目标状态定义副作用钩子，保证库存扣减、支付确认与配送单生成强绑定。

（3）**多因子加权派单调度算法**。对距离、负载、评分三因子归一化后加权排序，实现系统派单、抢单与人工指派三种通道，并持久化派单日志。

（4）**配送费计算规则引擎**。将起步价、里程费、夜间附加费与满额免运参数化到配送区域，以策略模式实现可配置的运费试算。

（5）**效期约束下的库存管理**。设计总库存乐观锁扣减与批次 FEFO 出库两层模型，保证取消订单时按原批次回补。

（6）**系统实现与测试验证**。完成三端功能实现，并以功能、接口、性能与安全测试验证系统满足验收标准。

## 1.4 论文组织结构

本文共七章：第 1 章绪论，阐述研究背景、国内外现状与主要研究内容；第 2 章相关技术介绍，说明 Spring Boot、MyBatis-Plus、MySQL 与 Redis、Vue3 技术栈及 JWT 认证机制；第 3 章系统分析，从角色、功能、流程、数据与非功能需求五个维度展开分析；第 4 章系统设计，给出总体架构、功能模块、数据库、订单状态机、派单算法、运费规则与接口设计；第 5 章系统实现，介绍工程结构与各端功能的实现并展示关键界面；第 6 章系统测试，记录功能、接口、性能与安全测试的输入与结果；第 7 章总结与展望，总结实现范围，分析不足并展望真实支付、路径规划与动态调度能力。
